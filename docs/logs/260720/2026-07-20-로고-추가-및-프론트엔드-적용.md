# 로고 추가 및 프론트엔드 적용 (2026-07-20, feat5/add-logo)

## 개요

루트에 임시로 추가된 `logo.png`(요양원명 포함 워드마크), `logo2.png`(심볼 단독)를
웹 앱 자산으로 정리하고 사이드바·로그인 페이지·파비콘에 적용했다.

## 파일 재배치

| 기존 | 변경 | 비고 |
|---|---|---|
| `logo.png` (루트) | `apps/web/src/assets/logo-wordmark.png` | 161×76, 원본이 이미 투명 배경(32bpp ARGB)이라 그대로 사용 |
| `logo2.png` (루트) | `apps/web/src/assets/logo-symbol.png` | 원본 1254×1254(898KB)에 체커보드 배경이 픽셀로 박혀 있어 배경 제거 후 512×512(77KB)로 축소 |
| (신규) | `apps/web/public/favicon.png` | 심볼 64×64 축소본 |
| `apps/web/public/favicon.svg` | 삭제 | Vite 템플릿 기본 아이콘 |

심볼 배경 제거는 System.Drawing 기반 스크립트로 처리:
코너 픽셀 색을 기준으로 RGB 거리 40 미만 픽셀을 투명 처리, 40~80 구간은 알파를 선형 보간(가장자리 헤일로 완화).

## 코드 변경

- `apps/web/src/components/shared/app-shell.tsx`
  - 사이드바 상단의 "CareShift" 텍스트를 워드마크 이미지(`h-10`)로 교체.
  - 헤더의 하드코딩 문구 "해피케어 주간보호센터"를 "늘봄실버타운요양원"으로 수정.
- `apps/web/src/features/auth/login-page.tsx`
  - CardHeader를 심볼(`size-14`) + 워드마크(`h-9`) 중앙 정렬 레이아웃으로 교체, `CardTitle` 제거.
- `apps/web/index.html`
  - `lang="ko"`, 파비콘을 `/favicon.png`로 교체, title을 "늘봄실버타운요양원 근태관리"로 변경.

## 검증

- `pnpm --filter web exec tsc -b --noEmit` 통과.
- 심볼 PNG 투명 처리 결과 이미지 육안 확인(체커보드 제거 확인).
