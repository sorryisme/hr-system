# 2026-07-20 apps/mobile 신규 프로젝트 세팅

브랜치: `feat6/mobile-app-scaffold`

## 배경

종사자 대상 웹뷰형 휴가 신청 앱을 별도 프로젝트로 시작하기 위해 `apps/` 하위에 `apps/mobile`을 신설했다. 사용자 확인 결과 다음을 확정:

- 디렉터리/패키지명: `apps/mobile`
- 기술 스택: `apps/web`과 동일(Vite 8 + React 19 + Tailwind 4 + shadcn + TanStack Router/Query) — 팀 컨벤션·툴링 재사용, 컴포넌트는 앱별로 shadcn CLI로 개별 설치(공유 패키지 아직 없음)

## 구성

`apps/web`의 설정 파일(`vite.config.ts`, `tsconfig*.json`, `components.json`, `.oxlintrc.json`, `index.css` 디자인 토큰)을 그대로 복제해 브랜드 일관성과 컨벤션을 유지했다. 차이점:

- `package.json`: Orval·`generate:api` 스크립트 제외(백엔드 연동 필요해지는 시점에 구성 — CLAUDE.md 원칙)
- `src/components/shared/mobile-shell.tsx`: 데스크톱 사이드바(AppShell) 대신 최대 폭 `max-w-md`의 단일 컬럼 레이아웃 — 모바일 웹뷰 전용 루트 레이아웃
- `src/components/ui/`: 아직 비어 있음(.gitkeep) — 필요한 프리미티브만 이후 `shadcn` CLI로 추가
- `index.html`: `viewport-fit=cover` 추가(웹뷰 세이프 에어리어 대응), 타이틀을 "휴가신청"으로 구분
- `src/routes/index.tsx`: 플레이스홀더 홈("휴가 신청 · 준비 중") — 실제 기능은 후속 작업

## 워크스페이스 변경

- 루트 `package.json`에 `dev:mobile` 스크립트 추가
- 루트 `.gitignore`에 `apps/mobile/.vite/`, `apps/mobile/src/routeTree.gen.ts` 추가
- `CLAUDE.md` 프로젝트 구조·Frontend 절에 `apps/mobile` 반영(시니어 친화 UI 기준 적용 명시)

## 검증

- `pnpm install` — 워크스페이스 인식·의존성 설치 정상
- `pnpm --filter mobile build`(`tsc -b && vite build`) 통과 — `routeTree.gen.ts`는 최초 `vite build`/`dev` 실행 시 플러그인이 자동 생성(다른 앱과 동일 패턴, gitignore 대상)
- `pnpm --filter mobile lint`(oxlint) — 경고 1건(`routes/index.tsx`의 `only-export-components`)은 TanStack Router 파일기반 라우팅의 표준 패턴이며 apps/web 라우트 파일과 동일하게 발생하는 무해한 경고
- `pnpm --filter mobile dev` 기동 후 `curl`로 응답 확인 — 타이틀·favicon·viewport 메타 정상 반영
