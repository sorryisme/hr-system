# 2026-07-20 dev_plan 문서에 plan_0720 신설 내용 반영

브랜치: `docs/plan-0720-update`

## 배경

`docs/plan/plan_0717.md`(제품기획안)가 `docs/plan/plan_0720.md`로 갱신되면서 「4. 핵심 기능 요구사항」1번 항목에 "가. 근무표 작성기능"이 신설되고 기존 항목(가~마)이 한 글자씩 밀렸다(가→나 … 라→마→바). 개발 기획서(`docs/plan/dev_plan_0717.md`)는 이 신설분을 반영하지 않은 상태였다.

## 변경 내용

파일을 `docs/plan/dev_plan_0720.md`로 리네임(`git mv`)하고 아래 항목을 반영했다.

- **§3.1 범위 정의:** 신설 휴가 12종·지난 일자 근무표 변경 결재 요건을 제외 목록에 명시(D-20·D-21 참조).
- **§2.2 로드맵:** Phase 2 항목에 휴가 유형 12종 확장 추가.
- **§3.6 정책 결정표:** `D-20`(신설 휴가 12종 처리 — 근무표 직접 입력, D-18과 동일 패턴, 셀 표기만 결정 대기), `D-21`(지난 일자 근무표 변경 결재 요건 — 결재 유형·결재선 미정, 결정 대기) 신설.
- **§4.7.1 (신설):** 기본휴가 4종(경조·출산/유산·배우자출산·선연차) + 기타휴가 8종(수유시간·임산부 근로단축·육아기 근로단축·공민권 행사·임산부 건강진단·특수 건강진단·예비군·투표 참가) 인정시간 표. 처리 방식은 D-18 패턴을 따르되 신청·결재 대상(`approval_request.type`)에는 추가하지 않음을 명시.
- **§4.8:** "작성 기본 원칙"(한 달 단위 작성, 희망 연차·휴무 사전 반영), 근무 작성 규칙 확장(프리셋 적용, 시간 수정 시 "근무종류(시작~종료)" 표기), "수정/삭제 규칙"(작성단계/마감단계 알람 정책, 지난 일자 변경 시 결재 필요 — D-21) 신설.
- **§8 요약·부록A·부록B:** 신설 결정 항목(D-20·D-21) 반영해 카운트·집계 갱신.
- 문서 상단에 개정 이력 블록 추가(0720 반영 요약).
