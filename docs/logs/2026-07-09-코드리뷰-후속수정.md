# 코드 리뷰 후속 수정 (2026-07-09)

## 배경

`/superpowers:requesting-code-review`로 `feat/api-nestjs-structure` 브랜치(base `e20c985`, head `33a010c`)의 Prisma ORM 세팅 + v7 업그레이드 작업을 리뷰받았다. Critical 2건, Important 6건, Minor 2건이 나왔고, 전부 수정했다(#7 제외 — 사람 승인 확인이 필요한 항목이라 아래에 별도 기재).

## 수정 내역

**Critical**
1. `LeaveBalance.remaining` / `SubstituteHolidayBalance.remaining`에 `@default(dbgenerated("(granted - used - reserved)"))` 추가. 기존에는 `create()` 호출 자체가 막혀 D-9/D-10의 "관리자 수동 입력" 기능이 동작하지 않았다. 수정 후 실제로 `prisma.leaveBalance.create(...)`를 호출해 MySQL이 `remaining`을 정확히 계산하는지 확인했다(15 - 3 - 1 = 11).
2. baseline 마이그레이션(`20260709000000_init`)이 실제로 Prisma 엔진으로 실행된 적이 없었던 문제 — 이전 로컬 테스트는 이미 테이블이 존재하는 DB에 `migrate resolve --applied`로 우회했을 뿐이었다. 이번에 완전히 빈 DB(`carehome_tms_migrate_verify`, 테스트 후 삭제)에 `prisma migrate deploy`를 실제로 실행해 트리거(`trg_hist_no_update`/`trg_hist_no_delete`) 포함 21개 테이블이 전부 정상 생성됨을 확인했다.

**Important**
3. `apps/api/test/app.e2e-spec.ts`: `PrismaService`를 `overrideProvider`로 스텁 처리해 e2e 테스트가 실제 DB 연결 없이도 통과하도록 수정(이전에는 `AppModule`의 전역 `PrismaModule` 때문에 `test:e2e`가 암묵적으로 DB를 요구했는데, 이번 검증 전까지 아무도 `test:e2e`를 돌리지 않아 드러나지 않았었다).
4. `apps/api/src/main.ts`: `app.enableShutdownHooks()` 추가 — 없으면 SIGTERM 시 `PrismaService.onModuleDestroy`(`$disconnect`)가 호출되지 않는다.
5. `apps/api/src/prisma/prisma.service.ts`: 커넥션 풀/타임아웃/재시도가 드라이버 기본값 그대로라는 사실을 `TODO(사람 검토 필요 ...)` 주석으로 코드에도 남겼다(기존엔 로그 문서에만 있었음).
6. `PrismaService`가 `process.env.DATABASE_URL`을 직접 읽던 것을 `PrismaModule`의 `DATABASE_URL` DI 토큰(`useFactory`)으로 분리해 생성자에서 주입받도록 변경 — 테스트에서 오버라이드하기 쉬워졌다.
7. **(코드 수정 아님)** 이전 로그 문서에 "v7 업그레이드 요청 = 신규 의존성 승인"이라고 스스로 판단해 적어둔 문장이 있었다 — 리뷰에서 자체 승인 처리라고 지적받았다. 대화에서 `@prisma/adapter-mariadb`(런타임 드라이버), `dotenv`(devDependencies → dependencies로 런타임 이전) 추가에 대해 별도로 명시적 승인을 요청했고, 사용자가 승인했다(2026-07-09).
8. `apps/api/src/prisma/prisma.service.spec.ts`, `apps/api/src/bigint-json.spec.ts` 신규 추가 — `PrismaService`의 `DATABASE_URL` 누락 시 예외, `BigInt` JSON 직렬화 패치에 대한 테스트 커버리지 확보.

**Minor**
9. `BigInt.prototype.toJSON` 패치를 `apps/api/src/bigint-json.ts`로 분리하고, `as unknown as {...}` 캐스팅 대신 `declare global { interface BigInt { toJSON(): string } }` 앰비언트 타입 선언으로 교체(캐스트 없이 타입-세이프).
10. `main.ts`의 `import 'dotenv/config'`를 `import { config } from 'dotenv'; config({ override: false })`로 명시화 — "이미 설정된 env는 덮어쓰지 않는다"는 보장을 dotenv의 암묵적 기본 동작이 아니라 명시적 옵션으로 고정.
