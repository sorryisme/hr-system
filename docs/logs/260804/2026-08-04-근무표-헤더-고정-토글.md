# 근무표 직원/날짜 헤더 · 하단 요약 고정(freeze pane) 토글

## 배경

근무표는 직원 수·날짜 수가 많아 그리드가 커지면 스크롤 중 어느 직원/어느 날짜인지, 그리고 하단 요약(근무 인원/요양보호사 주·야간)이 어느 날짜 열에 해당하는지 파악하기 어렵다는 요청으로, ① 직원명 컬럼·날짜 헤더 행, ② 하단 요약 3행을 각각 독립적인 토글로 스크롤 중에도 고정할 수 있게 했다.

## 구현(apps/web)

### `schedule-grid.tsx`

- `ScheduleGrid`에 `lockHeaders`(상단 헤더 고정)와 `lockSummary`(하단 요약 고정) 상태를 각각 별도 `useState(true)`로 추가 — 두 토글은 서로 독립적으로 동작.
- `stickyNameClass`(직원명 컬럼)와 날짜 헤더 `<th>`의 `sticky` 관련 클래스(`sticky left-0`/`sticky top-0`/z-index)를 `lockHeaders`가 true일 때만 적용하도록 조건부로 변경. 배경색·구분선(`shadow`, `border`)은 고정 여부와 무관하게 항상 유지.
- 좌상단 모서리 셀(`직원 / 날짜` 라벨)은 기존에 `sticky left-0`만 있고 `sticky top-0`이 빠져 있어 세로 스크롤 시 헤더 행과 별개로 흘러가던 부분을 함께 고정되도록 보완(`lockHeaders && 'top-0 z-[4]'`, position은 `stickyNameClass`의 `sticky`를 재사용).
- `SummaryRow`에 `lockSummary`/`bottomPx` prop 추가. `lockSummary`가 true면 각 셀에 `sticky` + inline `style={{ bottom: bottomPx }}`를 적용해 하단에 고정. 요약행이 3개(근무 인원/주간/야간)라 겹치지 않도록 `SUMMARY_ROW_HEIGHT(38px)` 기준으로 각 행에 다른 `bottom` 오프셋(76/38/0)을 부여해 아래에서부터 쌓음. 라벨 셀은 `lockHeaders`(좌측 고정)와 `lockSummary`(하단 고정)가 동시에 켜지면 좌·하단 모서리가 되므로 헤더 코너 셀과 동일하게 가장 높은 z-index(z-[4])를 부여.
- 표 우측 상단에 `Switch`(shadcn 신규 추가) + `Label` 두 쌍으로 "직원/날짜 헤더 고정", "하단 요약 고정" 토글 UI 추가. 그리드를 감싸던 단일 `overflow-auto` div를 `flex-col` wrapper로 감싸고, 토글 행을 스크롤 컨테이너 바깥(위)에 배치해 스크롤해도 토글 자체는 항상 보이게 함.

### `components/ui/switch.tsx`

- 프로젝트 컨벤션(shadcn CLI로만 UI 프리미티브 추가)에 따라 `pnpm dlx shadcn add switch`로 신규 추가. 기존 `context-menu` 등과 동일하게 `@base-ui/react` 기반이라 추가 의존성 설치 없음.

### `components/shared/app-shell.tsx` (범위 밖이지만 함께 수정)

- 토글 동작을 실제 브라우저에서 확인하는 과정에서, 앱 전체 레이아웃 루트가 `min-h-svh`(최소 높이만 지정)로 되어 있어 내부 `overflow-auto` 컨테이너들이 실제로는 한 번도 넘치지 않고(각 단계 `scrollHeight === clientHeight`) 대신 문서(body) 전체가 늘어나며 스크롤되는 사전 버그를 발견함. 이 상태에서는 `position: sticky`가 어떤 화면에서도 동작하지 않음(스크롤 컨테이너 자체가 성립하지 않으므로).
- `min-h-svh` → `h-svh`로 변경해 루트 높이를 뷰포트에 고정, 내부 `main`(앱 셸)과 근무표 그리드의 `overflow-auto`가 실제로 내부 스크롤을 갖도록 수정. 대시보드/결재함 등 다른 화면은 콘텐츠가 뷰포트보다 작아 기존과 동일하게 보임(회귀 없음, 브라우저로 확인).

## 확인

- `pnpm --filter web exec tsc --noEmit -p tsconfig.app.json`, `pnpm --filter web run lint`(oxlint) 통과(기존에도 있던 `components/ui/*` fast-refresh 경고 외 신규 이슈 없음).
- 로컬 dev 서버(API+웹)로 `/roster` 화면 실제 렌더링 확인:
  - 헤더 고정 ON: 그리드를 세로로 끝까지 스크롤해도 날짜 헤더 행과 직원명 컬럼(좌상단 모서리 포함)이 고정된 채 유지됨.
  - 헤더 고정 OFF: 동일하게 스크롤하면 헤더 행/직원명 컬럼도 본문과 함께 스크롤되어 사라짐.
  - 요약 고정 ON: 세로 스크롤 시 하단 요약 3행(근무 인원/요양보호사 주간/야간)이 겹치지 않고 순서대로 쌓인 채 하단에 고정되고, 그 위 직원 행들이 뒤로 스크롤되어 사라짐. 가로 스크롤 시에도 요약행 라벨이 좌측에 계속 고정됨(좌·하단 동시 고정 케이스 확인).
  - 요약 고정 OFF: 하단 요약행도 본문과 함께 스크롤되어 사라짐.
  - 두 토글이 서로 독립적으로 동작함(하나만 켜고 끄기 가능)을 확인.
  - `/dashboard`, `/approvals` 화면에서 `app-shell.tsx` 변경으로 인한 레이아웃 회귀 없음을 확인.

## 추가 수정 — 직원명 컬럼은 헤더 고정 대상에서 제외

- 최초 구현은 "직원/날짜 헤더 고정" 토글 하나로 날짜 헤더 행(위쪽 고정)과 직원명 컬럼(왼쪽 고정)을 함께 제어했으나, 요청에 따라 직원명 컬럼의 좌측 고정을 제거하고 토글은 날짜 헤더 행(top-sticky)만 제어하도록 변경.
- `stickyNameClass`에서 `lockHeaders` 조건부 `sticky left-0`를 제거해 정적 클래스(배경·구분선만)로 변경 — 직원명 컬럼은 헤더/바디/요약행 어디서도 더 이상 좌측 고정되지 않음.
- 헤더 좌상단 모서리 셀(`직원 / 날짜` 라벨)은 날짜 헤더 `<th>`와 동일하게 `lockHeaders && 'sticky top-0 z-[3]'`만 적용 — 더 이상 좌측 고정과 결합되지 않으므로 별도 z-[4] 보정 불필요.
- 하단 요약행 라벨 셀도 좌측 고정 요소가 사라져 z-index를 z-[4]→z-[3]으로 단순화(데이터 셀과 동일).
- 토글 라벨 텍스트를 "직원/날짜 헤더 고정" → "날짜 헤더 고정"으로 변경해 실제 동작과 일치시킴.
- 브라우저에서 `getComputedStyle`로 직접 확인: 헤더 모서리 셀은 `position: sticky; left: auto; top: 0px`, 바디 직원명 셀은 `position: static`, 요약행 라벨 셀은 `position: sticky; left: auto; bottom: ...px` — 직원명은 어디서도 좌측 고정되지 않고 날짜/요약 고정만 동작함을 확인.

## 추가 수정 — 직원명 컬럼 고정을 별도 토글로 재도입 + 고정 셀 불투명화

- 직전 수정에서 제거했던 직원명 컬럼 좌측 고정 기능을 "직원 헤더 고정"이라는 별도 토글로 재도입. 이제 날짜 헤더(위)/직원명 컬럼(왼쪽)/하단 요약(아래) 3개 토글이 서로 완전히 독립적으로 동작.
- `stickyNameClass`를 다시 `lockEmployees` 조건부 `sticky left-0 z-[2]`로 변경. 헤더 좌상단 모서리 셀과 요약행 라벨 셀은 두 축(위/아래 + 왼쪽)이 동시에 고정될 수 있어 z-index를 상황별로 계산(단일 축 고정 z-[2]/z-[3], 양쪽 축 동시 고정 z-[4])하도록 정리.
- **고정 셀 불투명화**: 스크롤 중 다른 행/열이 고정된 셀 뒤로 비쳐 보이는 문제를 막기 위해, 실제로 고정(sticky)되는 셀에 한해 반투명 강조색을 불투명 색상으로 교체:
  - 날짜 헤더의 전월 미리보기(readOnly) 배경: `lockHeaders`가 켜졌을 때만 `bg-muted/40` → `bg-muted`(불투명)로 전환.
  - 하단 요약행의 전월 미리보기 배경도 동일하게 `lockSummary` 켜졌을 때 `bg-muted/40` → `bg-muted`.
  - 하단 요약행의 인원 부족(shortage) 강조 배경: `lockSummary` 켜졌을 때 `bg-reject/10 text-reject` → `bg-reject text-reject-foreground`(불투명 + 대비 텍스트 색 전환).
  - 결재 항목 선택 시 강조되는 직원 행(name 컬럼)의 배경: `lockEmployees` 켜졌을 때 `bg-warning/10` → `bg-warning`으로 전환하고, 안쪽 이름/직무 텍스트도 `text-warning-foreground`로 바꿔 대비를 확보.
  - 토글이 꺼져 있어 해당 셀이 실제로 고정되지 않는 상태에서는 기존의 옅은 반투명 스타일을 그대로 유지(불필요하게 색을 진하게 바꾸지 않음).
  - 고정과 무관한 일반 본문 셀(주말 음영 `bg-paper/50`, 전월 셀 칩 `opacity-60`, 조정 근무 칩 `opacity-70` 등)은 애초에 스크롤 시 다른 콘텐츠 위로 고정되지 않으므로 변경하지 않음.

## 범위 밖

- 헤더/직원/요약 고정 여부를 로컬스토리지 등에 영속화하지 않음(페이지 재방문 시 기본값 ON으로 초기화). 요청에 명시되지 않아 우선 컴포넌트 상태로만 구현.
- 강조색(bg-warning, bg-reject)을 불투명하게 바꿀 때 디자인 토큰에 이미 정의된 `-foreground` 짝(예: `warning-foreground`, `reject-foreground`)만 사용했고 임의 색상값은 추가하지 않음(CLAUDE.md 준수).
- `app-shell.tsx`의 `min-h-svh`→`h-svh` 변경은 근무표 헤더 고정 기능이 실제로 동작하기 위한 선행 조건이라 함께 수정했지만, 앱 전체 스크롤 동작에 영향을 주는 공용 파일 변경이므로 별도로 유의가 필요함.
