# 근무표 셀 편집 팝오버에서 연차/오전반차/오후반차/병가 제외

## 배경
근무표 셀 클릭 시 뜨는 "근무유형 선택" 팝오버(`CellEditPopover`)에 등록된 모든 근무유형이 노출되어,
휴가·결재 흐름으로만 반영되어야 할 연차(AL)/오전반차(HAM)/오후반차(HPM)/병가(SICK)도 관리자가 셀에서
직접 지정할 수 있었다. 해당 유형들은 휴가 신청·승인 흐름을 거쳐야 하므로 셀 직접 편집 대상에서 제외한다.

## 변경 내용
- `apps/web/src/features/roster/cell-edit-popover.tsx`
  - `EXCLUDED_CODES`(AL, HAM, HPM, SICK) 상수 추가
  - `useListShiftTypes` 조회 결과에서 해당 코드를 필터링하여 팝오버 목록에 노출하지 않도록 수정

## 비고
- 근무유형 정의(shift_type) 자체는 그대로 유지되며, 범례(`labels.ts`)나 다른 화면(휴가 신청 등)에는 영향 없음.
- 백엔드 API/DB 변경 없음, 프론트엔드 표시 목록만 필터링.
