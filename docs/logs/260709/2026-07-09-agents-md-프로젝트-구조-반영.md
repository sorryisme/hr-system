# AGENTS.md / CLAUDE.md 프로젝트 구조 반영 (2026-07-09)

## 배경

`AGENTS.md`와 `CLAUDE.md`는 내용이 동일하게 유지되는 짝 파일(제목 줄만 다름)이며, 기존에는 프로젝트의 실제 디렉터리 구조에 대한 설명이 없었다. 현재까지 작성된 구조를 반영해 두 파일에 동일한 "프로젝트 구조" 섹션을 추가했다.

## 변경 내용

두 파일의 인트로 문단과 `## Architecture` 섹션 사이에 `## 프로젝트 구조` 섹션을 삽입:

- `apps/api`, `apps/web`의 현재 디렉터리 트리와 각 파일/디렉터리의 상태(구현 여부) 주석.
- `docs/` 하위 폴더(`architecture`, `plan`, `ddl`, `mock-ui`) 및 산출물 파일 네이밍 규칙(`{날짜}-{작업제목}.md`) 명시.
- Orval 미연동, `apps/web`의 `components/shared`·`features`가 뼈대만 있다는 현재 상태를 명확히 표기해 향후 작업자가 "이미 구현된 것"으로 오인하지 않도록 함.

## 근거

- `docs/setup-log.md` (초기 셋업 산출물)
- 실제 파일시스템 확인 (`apps/api/src`, `apps/web/src`, `docs/*`)
