# 프리셋 적용 다이얼로그 — 조 선택에 실제 패턴 표기

## 배경

`apps/web`의 프리셋 적용 다이얼로그(직원 행 우클릭 → 근무 패턴 · 조 · 시작일 · 적용 기간)에서 조 선택지가 "1조", "2조", "3조"처럼 번호만 보여줘, 관리자가 그 조가 실제로 어떤 순환 패턴(주/야/휴 등)으로 적용되는지 미리 알 수 없었다. "N조(주주야야비비)"처럼 실제 적용될 패턴을 함께 보여달라는 요청을 받았다.

## 변경 사항

- `apps/web/src/features/roster/apply-preset-dialog.tsx`: `teamPatternLabel(items, teamNo)` 헬퍼 추가 — `GET /rosters/shift-pattern-presets` 응답의 `preset.items`(조×일차별 `cellLabel`)를 해당 조 번호로 필터링 후 `dayIndex` 순으로 정렬·연결해 "주주야야휴휴" 같은 문자열을 만든다. 백엔드는 이미 이 데이터를 내려주고 있어 API 변경 없이 프론트에서만 조합했다.
- 조 선택 `Select`의 트리거 표시값과 각 `SelectItem`을 `{n}조` → `{n}조({teamPatternLabel(...)})`로 변경.

패턴 문자는 실제 `shift_type.cell_label` 값을 그대로 쓰므로, 데모 시드(주야비 3조 2교대)에서는 "1조(주주야야휴휴)"처럼 표시되고 다른 근무유형·프리셋이 등록돼도 그대로 반영된다.
