# 근무표 마감 상태머신 단순화 (작성완료·마감결재 → 마감/마감취소)

## 배경

기존 근무표 상태머신은 `DRAFT(작성중) → COMPLETED(작성완료) → CLOSING_APPROVAL(마감상신) → CLOSED(마감)`
4단계였다. 이를 `DRAFT ↔ CLOSED` 2단계로 단순화하고, 마감/마감취소 권한을 DIRECTOR(시설장)·
OFFICE_MANAGER(사무국장)에게만 부여하도록 변경했다.

## 변경 사항

### DB (`apps/api/prisma`)
- `RosterStatus` enum: `DRAFT | COMPLETED | CLOSING_APPROVAL | CLOSED` → `DRAFT | CLOSED`
- `ValidationSnapshotStage` enum: `COMPLETED` 제거(`EDIT | CLOSE`만 유지)
- `Roster.submittedBy` / `Roster.submittedAt` 컬럼·FK(`fk_roster_submitter`)·`Employee.rostersSubmitted`
  관계 제거(더 이상 별도 "마감 상신" 단계가 없음)
- 마이그레이션: `20260804000000_roster_close_cancel_simplify` — 기존 `COMPLETED`/`CLOSING_APPROVAL`
  데이터는 `DRAFT`로 백필 후 enum 축소. `validation_result.snapshot_stage`의 기존 `COMPLETED`
  스냅샷은 `CLOSE`로 relabel하지 않고 삭제한다(백필로 `DRAFT`가 된 근무표에 "마감 시점" 감사 기록이
  남거나, 실제 `CLOSED`로 남는 근무표의 진짜 `CLOSE` 스냅샷과 중복되는 것을 방지 — 코드리뷰 반영)

### 백엔드 (`apps/api/src/roster`)
- `RosterStateService.complete()` / `submitClose()` / `rejectClose()` 삭제
- `close()`: `DRAFT → CLOSED`로 직접 전이(기존 `CLOSING_APPROVAL → CLOSED`에서 변경). D-19 강행마감
  로직(위반 시 사유 필수)은 그대로 유지
- `reopen()` 신규: `CLOSED → DRAFT`, 사유 없이 즉시 편집 가능 상태로 복귀. `closedBy/closedAt/
  forceClosed/forceCloseReason`을 초기화
- `assertCloserRole()` 신규: `close`/`reopen` 호출 시 `actorJobRole`이 `DIRECTOR` 또는
  `OFFICE_MANAGER`가 아니면 403(`PERMISSION_DENIED`). system_role이 ADMIN 하나로 뭉뚱그려져
  있어(`permissions.guard.ts`) `roster:close` 권한만으로는 시설장/사무국장을 구분할 수 없기
  때문에, 앱 레벨에서 `Employee.jobRole`을 추가로 검사하는 방식을 택함(RBAC 테이블 미도입 상태이므로
  최소 변경)
- `RosterController`: `POST :id/complete`, `POST :id/submit-close`, `POST :id/reject-close` 제거,
  `POST :id/reopen` 신규 추가(`POST :id/close`는 유지). `close`/`reopen` 모두 컨트롤러에서
  `user.jobRole`을 서비스로 전달
- `RejectCloseDto` 삭제

### 프론트엔드 (`apps/web/src/features/roster`)
- `roster-toolbar.tsx`: 작성완료/마감상신/마감승인/마감반려 4개 버튼·다이얼로그를 마감/마감취소
  2개로 축소. `getSessionUser().jobRole`이 DIRECTOR/OFFICE_MANAGER가 아니면 버튼을 숨김(실제 권한
  판단의 단일 소스는 서버 403 — 프론트는 UX용 노출 제어만)
- `schedule-grid.tsx`: 편집 가능 조건을 `status === 'DRAFT'`로 단순화
- `labels.ts`: `ROSTER_STATUS_LABELS`에서 `COMPLETED`/`CLOSING_APPROVAL` 제거
