## 2. roster 모듈 스캐폴딩

`apps/api/src/roster/` 신설. 기존 `approvals` 모듈 컨벤션 준수
(PrismaService, BigInt/Decimal→string 명시 변환, `satisfies Prisma.*Include`, `{code,message}` 에러, class-validator + Swagger).

```
src/roster/
├─ roster.module.ts
├─ roster.controller.ts        @Controller('rosters'), @ApiTags('rosters')
├─ roster.service.ts
└─ dto/
   ├─ roster-query.dto.ts       yearMonth(YYYY-MM) 검증
   └─ roster-response.dto.ts    Cell/EmployeeRow/TeamGroup/DaySummary/Response
```

### 구현 완료 엔드포인트
| 메서드 | 경로 | 권한 | 설명 |
| --- | --- | --- | --- |
| `GET` | `/rosters?yearMonth=YYYY-MM` | `roster:read` | 목업 렌더용 단일 조회(헤더+팀별 직원+셀+하단 요약) |
| `POST` | `/rosters` | `roster:write` | 빈 DRAFT 월 근무표 생성(중복 시 409) |

- `facilityId`는 쿼리로 받지 않고 **세션 사용자(`@CurrentUser().facilityId`)** 에서 결정 → 타 시설 근무표 조회 차단(멀티테넌트 격리).
- **하단 요약 계산:** `workingCount = counts_as_work 셀 수`, 주간=`!crossesMidnight`·야간=`crossesMidnight`, 요양보호사(`CAREGIVER`) 주/야 인원을 `daily_staffing_rule`(teamId=null) `min_count`와 비교해 `dayShortage/nightShortage` 산출.
- **셀 시각 표기:** `startTime = override_start_time ?? shift_type.start_time`(HH:mm), `isTimeOverridden`으로 `"근무종류(시작~종료)"` 표기 여부 전달. `carryableMinutes`는 `sourceLedger` 연동 시 `유(h,m)` 표기용.

### 권한
`permissions.guard.ts` `ROLE_PERMISSIONS`에 `roster:read/write/close` 추가(SUPER_ADMIN·ADMIN 동일 부여).
> `roster:write`(작성=사회복지사) vs `roster:close`(마감=사무국장·시설장) 차등은 `system_role`이 둘 다 ADMIN이라 미구현 — `job_role` 앱 레벨 검사 또는 RBAC 도입 시 해소(§1.3, **결정 대기**).

### 후속(주석으로 명시, 미구현)
`PATCH /entries`, `apply-preset`, `complete`, `submit-close`, `close`(D-19 강행), `reject-close` 상태머신 + 결재 승인 이벤트 구독(→ `source=APPROVAL` 셀 반영).
**선행 확정 필요:** D-21(지난 일자 변경 결재), roster 권한 차등.
