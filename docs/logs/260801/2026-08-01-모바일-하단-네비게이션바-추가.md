# 모바일 하단 네비게이션바 추가

## 배경

`feat15/mobile-attendance` 브랜치에서 출퇴근 기능을 본격적으로 구현하기 전, 여러 탭(홈/휴가)을 오갈 수 있는 하단 네비게이션바를 먼저 추가했다. 기존 `apps/mobile`은 라우트가 `/`(휴가신청)와 `/login` 뿐이라 탭 구조가 없었다.

## 변경 사항

- 라우트 재구성
  - `/` — 새 홈 탭. 출퇴근 기능(GPS 태그) 구현 전까지의 자리표시자 화면(`features/attendance/attendance-home-page.tsx`)을 연결.
  - `/leave` — 기존 휴가신청 화면(`LeaveRequestPage`)을 이동.
  - `routeTree.gen.ts`는 `vite build`로 재생성(TanStack Router 플러그인 자동 생성 파일, 수기 수정 금지 컨벤션 준수).
- `components/shared/bottom-nav.tsx` 신규 추가
  - 홈/휴가 2탭, 아이콘(lucide-react) + 라벨 텍스트 구성, 활성 탭은 `text-primary`로 강조.
  - `apps/web`의 `AppShell` 사이드바 내비게이션과 동일한 `Link`/`activeProps`/`cn` 패턴 사용.
  - 터치 타깃 48×48dp 이상 확보(`min-h-14` + 아이콘/라벨 padding), 시니어 친화 가이드(N-7) 준수.
- `components/shared/mobile-shell.tsx` 수정
  - `min-h-dvh` 페이지 스크롤 구조 → `h-dvh` + 내부 `main` 스크롤 구조로 변경해 하단 탭바가 항상 화면에 고정되도록 함.
  - `/login`에서는 `useRouterState`로 경로를 확인해 네비게이션바를 숨김(기기 미등록 상태에는 탭 전환 불필요).

## 확인

- `pnpm --filter mobile exec vite build` — 정상 빌드, `routeTree.gen.ts`에 `/`, `/leave`, `/login` 3개 라우트 반영 확인.
- `pnpm --filter mobile run lint` — 신규/변경 파일 관련 경고 없음(기존 shadcn 컴포넌트 경고 2건은 무관).
- Chrome에서 `/leave` ↔ `/` 탭 전환, 활성 탭 강조, 휴가 잔여일수 데이터 렌더링 육안 확인.
