## Phase 0 — 공통 기반: 거의 구현됨

- 자체 JWT 인증(HS256) + httpOnly 쿠키, `JwtAuthGuard`+`PermissionsGuard`(RBAC) — 구현 (260719)
- 기기 등록(관리자 발급 코드 → 자동 로그인, C-13) — 구현 (260721)
  - 단, **관리자 측 코드 발급 화면·기기 원격 로그아웃 화면은 미구현** (기기 분실 시 API 자체가 없어 `revokedAt` 직접 조작 외 방법 없음)
- 팀 정의·직원 마스터 — 시드 데이터로 존재(9개 팀×3명 → 이후 24명 확대), 관리 화면(A-5)은 별도 로그 없음 → **UI 미구현 추정**
- 서명 이미지 등록 — 로그에서 확인 안 됨 → **미구현**

## Phase 1 — 결재 시스템: 핵심 흐름 구현, 일부 정책 미구현

### 구현됨
- 신청/결재 API, 결재선 1~3단계 + 전결(D-13, 자동 처리 + 2차 임의전결 옵션까지)
- 자기결재 금지(D-6), 대결자 허용, 낙관적 동시성 가드
- 상위 단계 결재자의 하위 단계 대리 승인(계획서엔 없던 확장)
- 잔여 관리(reserved/차감), 이중신청 차단(D-2), 사후신청 자동판정(D-3)
- 취소(CANCEL) 워크플로우: PENDING 즉시취소, INTERIM_APPROVED는 별도 결재 요청 생성
  - 단, **결재선을 1단계로 단일화**해 사양(§3.4의 표준 3단계 취소 결재)과 다르게 구현됨
- 결재함 UI(탭, 상세 패널, 이력 타임라인, 배지)

### 미구현/차이
- `CANCELED_AFTER_APPROVAL`(최종 승인 후 취소) 상태 — 끝까지 미구현
- 유대 관리대장(A-4, ledger, D-15) — Prisma 스키마(`SubstituteHolidayLedger`)만 있고 API/화면 로그 없음 → **미구현**
- 근무자 확인 서명(D-16), 서명 이미지 등록/전자서명 결재란 기재 — 미구현
- 연차 소멸 임박 알림(D-10 근거 C-10), 알림 채널(D-7) — 실제 알림은 대부분 Logger만, notification 연동 갭으로 명시됨
- 감사로그 뷰, 출력용 서식(PDF) — 로그 없음

## Phase 2 — 근무표 작성 엔진: 상당 부분 구현

### 구현됨
- 상태머신 DRAFT→COMPLETED→CLOSING_APPROVAL→CLOSED, 마감 시 위반 강행사유(D-19)
- 셀 편집(클릭/드래그 다중선택), 시간 수정 표기(`주(08:50~19:00)`), 프리셋 적용 + **월경계 연속성 규칙**(A-2)
- 결재 승인 이벤트 구독 → 가반영(글자, `is_provisional`)/확정 반영, 반려·취소 시 셀 원복(`pre_approval_snapshot`)
- 실시간 검증 패널(§4.8): 월 기준근무시간(§4.1), 직군별 필요/환산 인원(§4.2), 가산 3종(§4.3) 계산 — `configMissing` 처리 포함
- 결재함-근무표 요약 병행 표시(260720 시점 갭이었으나 이후 사이드바 연동)

### 미구현/차이
- 신설 휴가 12종(D-20, §4.7.1) — 셀 표기 코드/색상 결정 대기 상태 그대로, 근무표 직접 입력 UI 반영 여부 로그에 없음
- D-21(지난 일자 근무표 변경 결재 요건) — 계획서와 동일하게 여전히 **결정 대기**로 남아있고, 편집 API 범위에서 명시적으로 제외됨
- job_role별 권한 차등(사회복지사=작성, 사무국장/시설장=마감) — 전원 ADMIN 권한이라 **미구현**
- 대시보드(A-1) — 260719에 페이지는 구현됐으나 §4.9의 6개 카드(가산 점수, 연차 소멸 임박자 등)와의 일치 여부는 로그상 불확실, 별도 로그 없음
- 설정 화면(A-6: 고시 파라미터, GPS, 인원 기준 CRUD) — 시드로만 값 주입, 화면 미구현

## 종합 요약

Phase 1(결재)과 Phase 2(근무표) 핵심 로직·화면은 상당히 진행됐고, 계획서에 없던 확장(상위단계 대리승인, 임의전결)도 일부 있다. 반면 계획서상 Phase 1의 완결 조건이었던 **유대 관리대장·근무자 서명**, Phase 2의 **휴가 12종 셀 표기·설정 화면(A-6)**, Phase 3의 **미태그 워크플로우**, Phase 4 전체(**내보내기**)가 비어 있어 이 부분이 다음 우선순위로 보인다.

D-21(지난 일자 근무표 변경 결재)은 기획·구현 양쪽에서 계속 결정 대기 상태로 남아있어, 파일럿 전 확정이 필요하다.
