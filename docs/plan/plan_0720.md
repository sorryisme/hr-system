# 💮늘봄링크(가칭) 기획안

## 1. 프로젝트 개요

1. **목적:** 장기요양보험 고시 기준을 준수한 정확한 근태관리 프로그램 제작 → 근무관리 업무 효율성 증진
2. **사용자 및 특성**
    
    
    | 구분 | 대상 | 특성 | UIUX 설계 방향 |
    | --- | --- | --- | --- |
    | 관리자 | 사무국장, 사회복지사 | 데스크톱 환경에서의 작업
    고시,수가,근로기준법에 대한 지식보유 | -전체 현황이 보이는 밀도 높은 화면
    -주요 이벤트를 확실하게 표시
    -이벤트별 식별이 직관적으로 구분되어 검증에 용이하도록 |
    | 근무자 | 평균 60세 이상의 여성 근로자로
      1. 시력,청력 등 신체기능 노화
      2. 평균 학력 초졸
      3. 기술변화에 보수적 | 작은 글씨와 복잡한 UIUX 사용시 어려움 | -쉬운 용어
    -큰 텍스트와 버튼
    -화면당 1개의 과업
    -확실한 피드백0 |
3. **사용 흐름**
    - 관리자
        - 근무표 작성 → 검토 → 근무자에게 발송 → 연차 등 근무 수정사항 확인 → 수정사항 반영 → 근무자에게 발송
        - 출퇴근 현황 확인 → 미태그 출퇴근자 확인 및 알람 전송 → 출퇴근 기록 확인 → 지각, 조기퇴근자 확인 및 조치
        - 휴가신청 확인 → 결재 → 근무표 반영
        - 작성 문서 확인 → 보고서 형태 출력 → PDF 또는 EXCEL(xlsx) 선택하여 출력 → 게시판 게시 or 감사자료 제출
    - 근무자
        - 근무표 확인 → 본인 및 같은 팀 근무 확인
        - 출퇴근 태그 → 출퇴근 태그 확인 → 미태그 알림 수신 → 사유 기재 후 제출 → 수정된 근태 현황 확인
        - 휴가 신청 → 희망 휴가일 선택 → 휴가 사용여부 확인 (잔여연차 여부, 당일 같은팀원 휴가 여부) → 신청서 제출 → 승인 대기 상태 → 승인 시 알람 수신 → 반영된 근무표 확인
        - 근무조정 신청 → 희망 조정일 선택 → 사유 작성(필수) → 승인대기 → 승인 시 알람 수신 → 반영된 근무표 확인
        
4. **개발 범위**
    
    
    | 개발항목 | 관리자 | 근무자 |
    | --- | --- | --- |
    | 근무표 | -근무표 CRUD
    -근무표 검증 | -근무표 확인 |
    | 출퇴근 | -출퇴근 확인
    -출퇴근 수정 | -출퇴근 기록 |
    | 휴가신청 | -휴가 신청 결재
    -휴가 수 조정
    -근무표에 휴가 반영 | -휴가 신청
    -휴가 신청 상태 확인 |
    | 유급휴일대체 관리 | -유급휴일대체일 확인 및 근무표 내 인정시간 관리
    -유급휴일대체 관리대장 관리(감사용) | -잔여 유급휴일대체 확인
    -유급휴일대체 확인 서명 |
    | 기타 | -대장, 보고서 형태의 출력가능한 문서  |  |

## 3. 사용자 역할 및 권한

| 역할 | 권한 |
| --- | --- |
| 시설장 | 전체 설정, 근무표 확정/마감, 결재 최종 승인, 사용자 관리 |
| 사무국장 | 전체 설정, 근무표 확정/마감, 결재 최종 승인 전까지(시설장 전결 가능), 사용자 관리 |

근무자는 자기 팀 외 근무정보 조회 불가능, 타인 개인정보 조회 불가능

## 4. 핵심 기능 요구사항 및 세부사항

1.  **[관리자] 고시 기준 기반 근무표 작성 엔진**
    
    **가. 근무표 작성기능**
    
    1. 기본
        1. 한 달 단위 근무표로 근무자당 일별 근무 스케줄 작성
        2. 희망 연차와 휴무일을 작성 전 미리 근무표에 반영하여 근무표 작성 (희망 연차(휴무) 수 제한 가능) 
    2. 근무작성
        1. 근무자 별 일 단위 근무 작성
        2. 직군별 주간, 야간 근무 시간 설정(프리셋) 및 적용 
        3. 모든 근무는 시간을 수정할 수 있음. 수정하는 경우 근무종류(근무시작~종료) 형태로 표기.
        4. 마감된 근무표에서 수정이 이뤄질 경우 근무자에게 알림 전송, 편집자에게 수정 확인 알람.
    3. 휴가작성
        1. 기본휴가(기준시간 인정(8시간))
            
            
            | 종류 | 인정시간 (1일 당) |
            | --- | --- |
            | 연차 | 8시간 |
            | 반차 | 4시간 |
            | 유급병가 | 8시간 (연간 30일 이내) |
            | 경조휴가 | 8시간 (본인 결혼 5일, 자녀 결혼 1일, 본인(배우자)의 부모 또는 배우자 사망 5일, 본인(배우자)의 조부모 또는 외조부모의 사망 2일, 자녀 또는 그 자녀의 배우자 사망 3일, 본인 배우자의 형제 자매 사망 1일 |
            | 출산휴가, 유산(사산)휴가 | 8시간 총 60일(공휴일 근로자의 날 토요일 포함 연속해서 산정) |
            | 배우자 출산휴가 | 8시간 총 20일(3회 나누어 사용 가능) |
            | 선연차 | 근무기간 1년 미만 종사자, 3일이내, 초과 사용한 연차 유급휴가 발생일 전 퇴직 또는 근무시간 미충족등으로 발생 요건을 충족하지 못하는 경우 해당 근무시간 제외 |
        2. 기타휴가(**실제소요시간** 기준 인정)
            
            
            | 종류 | 인정시간 |
            | --- | --- |
            | 수유시간 | 2시간 내 |
            | 임산부 근로 단축 | 2시간 내 |
            | 육아기 근로 단축 | 2시간 내 |
            | 공민권 행사 | 8시간 내 |
            | 임산부 건강진단 | 8시간 내 |
            | 특수 건강진단 | 8시간 내 |
            | 예비군(민방위) | 8시간 내 |
            | 투표 참가 | 8시간 내 |
    4. 수정/삭제
        1. 근무표 단계 별 수정 시 알람 출력 (작성단계 - 알림없음, 마감단계 - 작성자에게 수정 반영 최종확인메세지, 근무자에게 수정 됨 알림)
        2. 이미 지난 일자 근무 변경시 결재 필요 (사유 기재)
    
    나. 월별/일별 적정 근무자 수 체크 기능.
    
    1. **월별** 적정 근무자 수 체크 기준
        - 월 기준 근무시간 산정 방식
        
        ```jsx
        월 기준 근무시간 = 토요일과 일요일, 공휴일을 제외 한 근무일 수 * 8.
        ```
        
        - **입소자 30명이상 노인요양시설 기준**
            - 시설장: 1명
            - 사무국장: 1명 (입소자 50명 이상인 경우로 한정)
            - 사회복지사 1명 (입소자 100명 초과 시마다 1명 추가)
            - 간호(조무)사: 입소자 25명당 1명.
            - 물리치료사(또는 작업치료사): 1명 (입소자 100명 초과 시마다 1명 추가)
            - 요양보호사: 입소자 2.1명당 1명.
            - 사무원: 1명 (입소자 50명 이상인 경우로 한정)
            - 영양사: 1명 (위탁급식 이용 시 면제)
            - 조리원: 입소자 25명당 1명. (위탁급식 이용 시 면제)
            - 위생원: 1명 (입소자 100명 초과 시마다 1명 추가) (위탁세탁 이용 시 면제)
            - 관리인: 1명 (입소자 50명 이상인 경우로 한정)
        - 근무자 산정 방식
            - 월 기준 근무시간에 충족 또는 초과 시 근무자 1인으로 인정
            - 월 기준 근무시간 미달 시
                
                ```jsx
                미달 근무자 직군별 근무시간 합산 / 월 기준 근무 시간 = 근무인원 수
                ```
                
                이때 근무인원 수에 대해서 가산 산정의 경우 소수점 이하는 버림, 감액 산정의 경우 소수점 둘째자리는 버리고 소수점 첫째자리가 4 이하인 경우 소수점 첫째자리는 버림
                
    2. **일별** 적정 근무자 수 체크 기준
        - 팀 단위로 그룹화
        - 그룹별 일일 근무 최소, 최대 인원 설정
        - 최소, 최대 설정값에 따라 과 부족 표시
    
    다. 근무자가 신청한 연차 확인 및 해당 연차 상신,반려 여부 결정
    
    라. 고시 기준(배치, 가산) 위반 시 실시간 경고 팝업 기능
    
    1. 가산 기준 위반은 목표 가산 점수를 관리자가 설정한 값을 기준으로 위반여부 판단.
    2. 가산의 종류와 산정 방법
        - 인력배치추가 가산
            
            인력배치 기준을 초과하여 배치하고, 추가로 배치한 직종 별로 별도 기준을 충족한 경우 가산함. 입소자 수를 근무인원 수로 나누어 계산하고 계산 결과 소수점 셋째자리에서 절사.
            
            - 간호(조무)사: 추가배치한 인원이 1인당 입소자 수가 19.0명 미만일때 1인으로 산정하며 1인당 1.2점
            - 사회복지사: 인력배치기준을 초과한 인원부터 1인으로 산정하며 1인당 1.4점
            - 물리(작업)치료사: 인력배치기준을 초과한 인원부터 1인으로 산정하며 1인당 1.4점
        - 야간직원배치 가산
            - 야간은 22시부터 다음날 06시 임.
            - 야간시간에 근무한 요양보호사 또는 간호(조무)사 1명 이상이 근무한 경우 0.9점 가산.
            - 추가 가산요건
                - 야간근무 직원 1인당 입소자 20인 이하
                - 주간(24시간 중 야간을 제외한 시간)에 근무하는 요양보호사와 간호(조무)사 수의 합이 야간직원의 2배 이상이어야 함.
                - 야간배치 인력수는 해당월의 각 일자별 22시부터 다음날 06시 사이에 근무한 요양보호사와 간호(조무)사의 실 근무시간을 합산하여 7로 나눈수를 급여제공일수로 나누어 계산. 소수점 이하 절사
                - 주간배치 인력수는 해당 월의 각 일자별 06시부터 22시까지 근무한 요양보호사와 간호(조무)사의 실 근무시간 및 제12조제1항에 따른 근무시간을 합산하여 14로 나눈 수를 급여제공일수로 나누어 계산. 소수점 이하 절사.
        - 간호사배치 가산
            - 간호사 1인당 0.6점
            - 입소자 50인 이상 노인요양시설의 경우 최종 간호사 가산점수에 0.2점을 더하여 산정.
    
    마. 근무 패턴(3조 2교대 등) 프리셋 적용 기능
    
    1. 근무형태: 주야비(주주야야비비 - 주간2일, 야간2일, 비번(휴일)2일)), 주간, 야간
    2. 프리셋형태:
        - 주야비 프리셋 - A,B,C조 프리셋. A조 주간2일 B조는 휴일 2일, C조는 야간2일을로 패턴시작 (예: A조: 1일-주간,2일-주간,3일-야간,4일-야간,5일-휴무,6일-휴무 / B조: 1일-휴무,2일-휴무,3일-주간,4일-주간,5일-야간,6일-야간/C조: 1일-야간,2일-야간,3일-휴무,4일-휴무,5일-주간,6일-주간)
    
    바. 근무자 별 근무시간이 월 기준근무시간에 충족하는지 판별, 미충족시 오류 출력
    
    1. 월 기준근무시간 산정 식 = 해당 월의 전체 일수 - 토,일 및 법정공휴일(대체공휴일포함) = 근무일 * 8시간 = 월 기준 근무시간
    2. 기준근무시간 인정: 일반근무,  연차(반차), 유급병가, 기타휴일(교육 등), 유급휴일대체(이 경우 공단에서 인정하는 유급휴일대체 시간으로 적용)
        
        ⇒ 위 공단에서 인정하는 유급휴일대체란, 유급휴일대체가 발생한 당월 기준근무시간을 초과한 시간분만 공단은 기준근무시간에 산입할 수 있도록 인정하며 이때 최대 8시간으로 한정한다. 예를들어 176시간 기준근무시간인 달에 법정공휴일에 근무하게 되어 초과시간이 182시간 20분인 경우 6시간 20분만 인정받을 수 있다. 다만 이 룰은 공단인정시간 산정에만 사용하고, 실제 근무자는 근로기준법에따라 연차와 동일하게 하루를 쉬고 이에대해 유급휴가와 동일한 급여를 산정받는다.
        
    3. 기준근무시간 불인정: 무급병가, 휴무, 결근, 휴직
2. **(추후 개발) 근로기준법 기준 근무표 검토 엔진**
    
    가. 세무사 협업 급여산정자료 export
    
    나. 노동법 위반 사항 검토, 위반 예방
    

**3.  [종사자] 간편 출퇴근 및 연차 신청 (모바일 웹/앱)**

가. GPS 기반 원터치 출퇴근 태그 기능 (지정 반경 내 활성화)

나. 연차, 유급휴일대체 신청서 작성 및 현황 조회

1. 연차는 1년차까지 1달 개근 시 익월 입사일 기준 1일씩 발생
2. 연차는 근속 1년차부터 15개 연차 발생. 3년차 16개, 5년차 17개 . . . (2년마다 1일 가산)
3. 유급휴일대체는 법정공휴일 근무 시 발생.
4. 근무표 상 표기는 법정공휴일 근무를 하게 된 월의 기준근무시간을 초과한 범위만 인정하며 최대 8시간까지만 산정. 당해년도만 산정 (25년→26년사용시 해당사항없음.)
1. **[공통] 결재 및 전자 문서화**
    
    가. 연차/근무조정 신청-승인/반려 워크플로우

    4. 직원: 연차신청(결재대기중) → 연차 로 변경되어 연차 승인이 난 것을 확인.

    2. 사내 게시용 근무표 형식

## 6. 화면정의

1. **A 관리자 웹 (데스크톱 우선)**
    
    **A-1. 대시보드**
    
    - **표시 요소:** ① 이번 달 직군별 인력충족 현황(충족/미달을 색+텍스트로), ② 오늘의 주간/야간 근무자 수 vs 설정 기준, ③ 미결재 신청 건수, ④ 가산 예상 점수 vs 목표 점수, ⑤ 고시기준 위반 경고 목록, 6. 연차 소멸 임박자 (입사일 도래 일 60일전 잔여연차 3개이상 남은경우 - 사용필요(노랑), 입사일 도래 30일전 잔여연차가 남은경우 - 조치필요(빨강)
    - **동작:** 각 카드 클릭 시 해당 상세 화면으로 이동.
    
    **A-2. 근무표 편집기 (핵심 화면)**
    
    - **레이아웃:** 세로축 = 직원(팀별 그룹핑, 팀은 직원등록 시 or 설정을 통해 변경가능), 가로축 = 해당 월의 일자(토요일, 일요일, 공휴일은 평일과 셀 색과 글자 색 구분되도록 표시). 셀 = 근무유형 코드(주간: “주”로 표시(노란색)/야간: “야”로 표시(파란색)/비: “휴”로 표시(회색)/연: “연”으로 표시(녹색)/오전반차: “오전”으로 표시(녹색)/오후반차: “오후”로 표시(녹색),유급휴일대체:”유”로 표시(녹색)되며 근무표화면에서만 몇시간 인정받는지 “유(인정된시간숫자,분)” 표기함. ).
    - **입력 방식:** 셀 클릭 → 근무유형 선택 팝오버. 드래그로 다중 셀 일괄 입력. 직원 행 우클릭 → "프리셋 적용".
    - **프리셋 적용 다이얼로그:** 패턴 선택(주야비 A/B/C조, 주간 고정, 야간 고정) + 시작일 + 적용 기간. 최초 설정 후 해당 근무자 전월 주야비 패턴 확인해 자동 입력.
    - **실시간 검증 패널(우측 고정):**
        - 월별 인력산정 결과(직군별 환산 인원 vs 법정 기준) — 편집할 때마다 재계산
        - 일별 주/야 인원 미달일 하이라이트(달력 미니맵)
        - 가산 예상 점수(인력추가/야간/간호사 각각)
    - **경고 팝업:** 저장 시점에 위반이 있으면 위반 항목 목록 + "그래도 저장"(임시저장만 허용) / "돌아가서 수정". **확정(마감)은 위반 존재 시 차단** — 근무표 마감 시 위반 사항 무시하고 마감하는 경우 로그 남김. 작성(저장), 수정, 마감은 모두 로그남김(작성자,일자,변경사항).
    - **상태:** 작성중 → 작성완료 → 마감결재(사회복지사)→ 마감(사무국장 또는 시설장) (마감 후 수정은 "휴가 및 근무조정 결재"를 통해서만).
    
    **A-3. 결재함**
    
    - 탭: 대기 / 승인 / 반려. 목록 항목: 신청자, 종류(휴가/근무조정), 대상일, 사유, 신청일시.
    - 상세에서 승인/반려(반려 사유 필수 입력). 사회복지사 결재 시 근무표에 반영(글자만), 최종 결재 승인 시 근무표에 승인된 연차 표시(셀 색칠) + 잔여 연차 차감.
    
    **A-4. 유급휴일대체 관리**
    
    - 이름, 근무일(유급휴일), 구분(주간,야간), 사용예정일자, 구분(주간,야간), 월기준근무시간(근무일기준), 실근무시간, 이월가능시간 으로 리스트 작성
    - 근무표에 입력시 사용예정일자에 자동으로 해당 일자 불러옴. 근무표 기준인정시간 산정 시 이월가능시간으로 산정 함.
    - 사용예정일자 입력된 근무자는 근무자 서명요청 보내기 → 근무자에게 요청알림
    
    #### A-5. 직원 관리
    
    - 직원 등록/수정: 이름, 직군, 입사일, 연차 부여 수, 근무 가능 형태(주간만/교대 가능), 재직 상태.
    
    #### A-6. 설정
    
    - **시설 정보:** 입소 정원, 월별 현원(입소자 수), **적용 배치기준(2.1:1 / 2.3:1 선택 — 유예기간 대응)**, 위탁급식/위탁세탁 여부(영양사·조리원·위생원 면제 판단).
    - **고시 파라미터:** 월 기준시간, 각 가산 점수·조건값
    - **일별 적정 인원:** 직군별 주간/야간 최소 인원.
    - **가산 목표:** 목표 가산 점수.
    - **출퇴근:** 사업장 GPS 좌표, 허용 반경(m), 태그 허용 시간 여유(교대 전후 n분).
    - **근무유형 정의:** 유형별 시작/종료 시각, 휴게시간(분), 야간 여부.
    
    #### A-7. 내보내기
    
    - 마감된 근무표(월) → Excel: ① 근무표 시트, ② 출퇴근부 시트(직원×일자, 출근/퇴근 시각, 실근무시간), ③ 인력산정 요약 시트.
    - 내보내기 파일에는 개인식별정보를 최소화(이름 외 연락처·주소 등 미포함).
    
2. **B 종사자 모바일 (시니어 친화)**
    
    #### B-1. 로그인
    
    - 최초 1회 관리자 발급 코드로 기기 등록 → 이후 자동 로그인. 아이디/비밀번호 입력을 매번 요구하지 않음.
    
    #### B-2. 홈 (출퇴근)
    
    - 화면의 70% 이상을 차지하는 단일 대형 버튼: 상태에 따라 "출근하기" / "퇴근하기" 텍스트 자동 전환.
    - 버튼 아래: 오늘 내 근무("오늘은 야간 근무입니다 · “근무시간”)를 한 문장으로.
    - 태그 성공 시: 전체 화면 초록 배경 + "출근 완료 · 오후 9시 52분" + 진동. 실패 시: 원인을 쉬운 말로("요양원에서 너무 멀리 있어요. 건물 근처에서 다시 눌러주세요.") + 관리자 호출 버튼(전화버튼-031-283-3211).
    - GPS 미수신/권한 거부 시 폴백: 수동 태그 요청 → 관리자 승인 큐로 전송.
    
    #### B-3. 내 근무표
    
    - -2일, +2일 근무 오른쪽에서 왼쪽 스와이핑하여 향후 근무 확인 가능, 맨 위에 일자 요일 아래, 위로 같은 팀 근무 본인 근무표보다 낮은 투명도로 보임. 월 근무표 (내 근무 + 팀원 보이는)는 별도 제공 (팀원 근무는 이름으로 제공)
    
    #### B-4. 신청
    
    - 연차 신청: ① 날짜 선택(큰 달력) → ② 종류(연차/반차/유급휴일대체) → ③ 확인 — 3단계 이내, 사유 입력은 선택사항.
    - 근무조정 신청: 대상일 + 희망 근무형태 + 사유(필수).
    - 신청현황: 대기(노랑)/승인(초록)/반려(빨강, 사유 표시)를 색+텍스트 병기.
